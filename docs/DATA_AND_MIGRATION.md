# 数据、备份与跨端迁移

Lexi 不把个人学习数据放在 Git 或安装包内。各平台数据目录、数据库身份和备份实现独立。

## Windows

- 默认数据目录：`%LOCALAPPDATA%\Lexi`。
- 主要存储：SQLite 词汇、计划、学习轨迹、记忆状态和金句数据。
- 升级采用数据库加法迁移，升级前应退出应用并备份整个数据目录。
- 安装和卸载不默认删除用户数据，但用户仍应保留独立备份。

## macOS

- 默认数据目录：`~/Library/Application Support/Lexi/`。
- 覆盖安装保留词库、计划、学习轨迹、金句、统计和记忆状态。
- DMG 内卸载脚本默认保留数据；只有明确选择删除并再次确认才清理 Lexi 自有数据。
- AI Key 由 macOS 钥匙串管理，不进入普通数据备份或词条导出。

## CSV 与 JSON

Windows 与 Android 使用兼容的 29 列词条 CSV 入口。可迁移 UUID、词义、音标、来源、原句、备注、标签、AI 内容和不含密钥的复习字段；最低旧格式和重复项策略以当前导入实现为准。

JSON 主要用于兼容旧版迁移。词条导入不会保证复制：

- 完整长期复习流水。
- FSRS 个人参数和内部记忆状态。
- 每日计划、进行中的会话或统计。
- 金句、好友关系和云端确认记录。

建议先导出原端备份，再用少量词条在目标端验证字段往返，最后批量导入。

## SQLite

不要把 Windows SQLite 直接覆盖到 macOS、Android 或其他数据库版本。各端数据库包含不同表结构、迁移版本和平台身份。直接替换可能损坏数据或让应用拒绝启动。

需要恢复整库时：

1. 完全退出应用。
2. 保留当前数据目录副本。
3. 使用本平台的恢复入口或说明恢复。
4. 启动后检查词条数、计划、学习记录和记忆状态。
5. 失败时停止继续写入并回退到安全副本。

## 一起学习

「一起学习」不需要上传完整词库。登录后，服务按用户授权同步账号资料、好友关系、当日达标和统计摘要。逐词记录、计划内容、金句、API Key 和个人 FSRS 模型不上传。

离线完成计划后进入待确认状态。双方在学习日后的补传窗口内联网确认，才会计入共同成功日。删除或撤回好友授权后，应按当前客户端和服务的清理行为验证本地缓存与访问权限。

## 导出不是备份

CSV、PDF、图片和打印稿用于交换或阅读，不是可完整还原应用的数据库备份。定期备份应包括平台数据目录和必要设置，并妥善保护，因为其中可能含个人学习内容。
