# Lexi 3.3.1 双平台发布

发布日期：2026-10-19

本次 Release 同时发布 Windows x64 与 macOS Apple Silicon 版本。两个平台继续使用各自的应用身份和数据目录；覆盖安装不会把另一平台的源码或资源写入用户数据目录。

## 下载

| 平台 | 安装包 | 校验文件 |
| --- | --- | --- |
| Windows 10 / 11 x64 | `Lexi-3.3.1-x64-setup.exe` | `Lexi-3.3.1-x64-setup.exe.sha256` |
| macOS 12+ / Apple Silicon | `Lexi-3.3.1-macOS-arm64.dmg` | `Lexi-3.3.1-macOS-arm64.dmg.sha256` |

安装包位于 GitHub Release `v3.3.1-cross-platform`。源码分别位于仓库的 `windows/` 与 `macos/`，不提交安装包、DMG 或用户数据。

## 主要变化

- 考试专题扩展到 IELTS、CET-4、CET-6、考研、GMAT、TOEFL、GRE。
- 加入 20 本考试词书，并按词书、单元和选中词条建立学习计划。
- 每个词书使用独立学习身份；同词跨书不会覆盖另一本书的未完成轮次。
- 考试词条接入今日重逢、淡写、默写、错词、统计与 FSRS-6。
- 新增可选「一起学习」：双人邀请、逐好友分享授权、共同学习日和预测曲线对照。
- 统一 Glacier Blue 视觉，补齐学习统计、备份轮换与数据库加法迁移。
- 修复复习卡内部 ID 展示、评分后无法继续、“忘记”后主操作不突出等问题。

## 数据与隐私

- 离线查词、词汇档案、计划、学习轨迹和金句默认只保存在本机。
- 「一起学习」仅在用户主动登录后同步账号资料、好友关系、当日达标和获授权的统计摘要。
- 完整词库、逐词历史、计划内容、金句、音频和个人记忆模型不上传。
- AI 服务由用户自行配置；API Key 保存在平台受保护存储或系统钥匙串。
- 公开源码、截图和安装包不含账号、Cookie、Session、Token、真实客户端配置、签名私钥或作者学习记录。

Windows 默认数据目录为 `%LOCALAPPDATA%\Lexi`；macOS 默认数据目录为 `~/Library/Application Support/Lexi/`。安装、更新和卸载的默认行为均以保留用户数据为前提。

## 兼容与已知边界

- Windows 安装包未使用商业代码签名证书，macOS DMG 未使用 Apple Developer ID，也未经过 Apple 公证。
- macOS 分发面向 Apple Silicon；未提供 Intel Mac 或通用二进制。
- Windows 全量 UI 自检存在宽度 1100 下的版面断言，不能把局部定向检查写成完整 UI 验收通过。
- 真实 GitHub OAuth、双平台好友邀请、撤权和云端存储回收需要独立测试账号完成端到端验收。
- Android 仍为 0.2.2-alpha 预览，固定复习规则尚未迁移桌面端 FSRS-6。
