# Lexi

本地优先的英语学习与词汇档案工具。查词、保存遇见的词、复习，并把学习内容带回自己的档案。

**Authors: Cofran-77 & DespairJasper** · [MIT License](LICENSE) · [macOS 协作入口](macos/README.md)

本仓库按平台保存源码，历史版本来自已有交付源码快照。Windows 与 Android 的能力、复习算法和数据格式并不完全相同；以各平台文档为准。macOS 暂只预留入口。

平台目录：`windows/`、`android/`、`macos/`。最新说明在 main 分支，重要节点使用带平台前缀的版本标签；第三方 IELTS 教材及录音不随源码发布。
