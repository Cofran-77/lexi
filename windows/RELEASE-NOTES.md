# Lexi 3.3.1 · Windows 累计升级

这是一次累计升级：从 3.1.3 功能基线一次更新到 3.3.1，不需要逐版安装 3.2.0—3.2.3。

- 视觉：Glacier Blue 浅色 / 深色语义 Token、卡片与留白层级、低存在感滚动条、减少动态效果支持；首页标题区不再出现大号品牌 Logo。
- 考试专题：IELTS、CET-4、CET-6、考研、GMAT、TOEFL、GRE 分组入口，新增 20 本考试词书、66,974 条按书独立身份保存的记录；同词跨书不串档，可进入计划、拼写、错词、今日重逢与 FSRS。
- 学习统计：初学、复习、拼写时长，学习词数、学习天数、连续天数、峰值、易忘词与趋势；预测数据与已观察数据分开标注；紧凑宽度下四项指标保持同行。
- 一起学习（可选）：复用同一 Supabase 项目与 GitHub OAuth；一对一好友、24 小时邀请码、逐好友逐方向分享授权、云端确认的共同学习日、72 小时补传窗口与 121 点平均稳定性预测曲线（预测，不是排名）。逐词历史、词库、个人 FSRS 状态与计划内容始终留在本机。
- 数据：SQLite 存储版本 3 为纯加法迁移，保留旧档案、词条 ID、计划引用、逐词记录、FSRS 状态、金句与设置；升级前自动备份，备份轮换与内部快照清理在体积预算内进行，不删除学习历史。
- 修复：复习卡不再显示内部 ID；评分后鼠标点“下一词”与按空格均可前进，连续作答不再冻结；“忘记”后只突出居中的“下一词”。

部署要求：Windows 默认使用 `http://127.0.0.1:<port>/auth/callback/` 本机回环完成 GitHub 登录，不要求为 Windows 单独放行回调；仅当本机回环监听无法启动时才使用 `com.lexi.windows://auth/callback`，此时需在同一 Supabase 项目的 Redirect URLs 中放行该协议地址。生产 `social-public.json` 由发布流程注入，仓库只保留示例文件。

Windows 安装包从当前发布源码重新生成，并包含按 `Cargo.lock` 构建的本地 FSRS 优化器。由于未使用商业代码签名证书，安装时系统可能显示“未知发布者”，请先核对 Release 页面和 SHA256。

发布前仍未完成的真实环境验证：真实 GitHub OAuth 登录回调、真实账号跨 Windows / macOS 的双向邀请与撤权，以及云端存储字节回收。以上均未在本次开发环境中端到端验证。
