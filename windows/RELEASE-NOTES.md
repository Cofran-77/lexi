# Lexi 1.1.2 Windows

1.1.2：统一侧栏“今日重逢”数字与实际待复习卡片队列，排除本轮已处理的词；全部处理后显示 0，重新置入今日或撤销复习后按实际待处理词数更新。本次按用户要求未运行测试或进行新版试用，由用户自行验证。

本次修复：查词页新增 Alt+Space 入库快捷键，支持输入框焦点并处理 Windows 系统菜单冲突；连续按键不会重复保存已收藏词。复习卡替换内容前完整退场，新卡片再平滑进入，避免旧动画结束回弹造成闪烁；切换页面会取消旧过渡，“减少动态效果”下直接切换。数据结构保持不变。

新增独立「今日重逢」卡片：先看单词与音标，点击或按 Space 查看释义，再选择记得/还不熟；左右键可评级，保存成功后横向移出卡片。释义再长，评级按钮保持在底部。待复习队列独立于词库筛选。

词汇档案紧凑行增加来源/标签；设置分为外观、查词快捷方式、AI语境、数据备份、关于诊断。外观增加高对比度、不透明背景、减少动态效果；设置显示当前词数、最后收藏时间和实际数据库路径。

代码实际拆分 Domain / Application / Infrastructure；移动原生体验方案见 MobileFeasibility/README.md。手机与平板运行验证尚未完成，当前仍只发布 Windows。

Lexi 用来保存真实阅读和工作中遇到的词。离线查词不消耗 AI Token，进阶内容由用户自选模型、按需生成。

本次升级新增个人词汇档案：来源、原句、备注、标签与遇见次数。AI 例句、同义词、反义词、常用词组可保存和编辑；支持日常表达、工作写作、学术阅读、技术文档和自定义偏好。原句仅在用户勾选附带时发送给所选 AI 厂商。

窗口保留深浅主题、磨砂和圆角，新增最小化、最大化/还原及边缘缩放，标题栏空白可拖动和双击。× 关闭到托盘，托盘右键退出。

设置增加数据目录、手动备份和恢复入口、CSV 与完整档案 JSON 导出。JSON 用于可移植词汇资料，SQLite 备份保留完整复习历史并用于恢复。升级使用事务与独立快照；安装程序只更新程序文件。记住的 API Key 改用 Windows 当前账户加密保护，换电脑需重新填写。

本版提供 Windows 10/11 x64 自包含安装包，不需要安装 .NET 或 WebView2。未配置商业代码签名。macOS、Android、iOS 尚未发布；已开始抽出可复用的档案与复习核心，各端将独立适配系统交互。

分享时发送 `Lexi-1.1.2-x64-setup.exe` 即可。完整分发包附使用说明和许可，源码包用于二次开发。不要发送 `%LOCALAPPDATA%/Lexi`，其中是个人词库及备份。
