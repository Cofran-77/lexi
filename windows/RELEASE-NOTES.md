# 1.2.0 · Windows 桌面体验与长期学习系统升级

Lexi 1.2.0 是针对 Windows 桌面体验与长期记忆系统的重要升级版本。本版本全面重构了学习计划、IELTS 工作区与学习卡片的视觉架构与交互流转，规范了 Windows 桌面设计系统，并深度整合了 FSRS-6 长期记忆自适应排期引擎。

## 核心更新与交互改进

### 1. 界面设计系统与窗口体验
- **中性操作按钮与主动作层级**：全局常规操作按钮回归中性白/深灰蓝表面与 1px 细边框，彻底清理误导性浅蓝背景；每个功能区域严格收敛为唯一实心蓝色强调主动作按钮（如“下一步”、“创建学习计划”）；已选状态采用低饱和冰蓝背景与细边框，与常规按钮明确分离。
- **窗口自适应与 760 窄窗支持**：默认视口为 1100×760 DIP，支持缩放自适应至 760×520 DIP 紧凑窄窗；紧凑模式下 IELTS 目录改为章节下拉框，学习操作栏换行，保留完整导航与评分操作。
- **Windows 标准标题栏控件**：关闭按钮对齐 Windows 交互规范（默认中性透明，仅在鼠标悬停与按压时显现系统警示红）；快捷查词/翻译卡清理重复关闭与双重标题栏。
- **品牌与离线生态保持**：完整保留应用原生 Logo 资产与 59,026 条 ECDICT 离线词库，保留历史版本目录，不触碰用户既有学习数据。

### 2. 两步计划创建流程
- **两步模态对话框**：重构计划创建流程为“第 1 步：选择词条”与“第 2 步：安排计划”，限制在有界弹窗内，从根源杜绝内容嵌套与表单重叠侵入。
- **有界词表与选词工具**：星号行独立滚动，提供“选本页”、“选当前筛选结果”、“清空”与“仅看已选”工具，跨搜索与跨分页严格保持已选集合；通用创建默认不强制全选。
- **显式冲突防范**：同来源计划冲突时提供清晰面板与显式确认，防止隐式误提交或连击重复创建。

### 3. 独立专注学习工作区
- **工作区彻底解耦**：将“计划管理概览”与“独立专注学习卡”物理分离，避免卡片与管理列表争抢外层滚动；提供 38 DIP 防截断词头。
- **连击强化与先学后测**：学习卡配备 `○ ○ ●` 轮内强化连击三格指示；新词严格执行“先看释义后进入回忆”；回忆卡先隐藏释义正文，揭晓后方可评分。
- **三键评分与撤销改判**：提供“认识 / 模糊 / 忘记”三级评分；评分后支持即时“撤销”（快捷键 Ctrl+Z / Alt+Z）或改判为“忘记”，完整回滚轮内进度与记忆状态。
- **灵活拼写闭环**：批次学习完成后提供淡写提示、无提示默写及错词重练选项。

### 4. 词汇档案式 IELTS 工作区
- **告别多按钮操作墙**：左侧章节目录采用 220 DIP 固定宽度独立滚动与低饱和克制指示；右侧词汇行采用与词汇档案一致的丰富档案式行设计（词头、音标、词性胶囊、单行释义、学习状态、紧凑发音、抽屉展开例句/来源/同义替换）。
- **挑选后批量学习**：支持勾选词条后呼出批量栏（显示“已选 N 词”），一键发起所选词的拼写训练或创建针对性每日学习计划。
- **紧凑音频播放器**：集成紧凑章节录音播放条，支持 Seek 进度拖动、时间进度显示与播放状态响应。

### 5. 记忆排期与会话一致性
- **FSRS-6 长期自适应算法**：今日重逢与计划学习全面接入 21 参数 FSRS-6 算法模型，真实到期时间由稳定性、难度、回忆记录和目标保持率计算，不按旧固定五阶段自动推进。
- **Source Due 多来源统一到期**：到期队列统一纳录个人词汇档案与 IELTS 教材等不同来源卡片，通过规范来源身份（WordKey）与独立排期协调统一，教材复习不污染个人档案。
- **可靠断点与持久化**：计划学习与复习队列支持会话级断点保存；退出学习或窗口切换自动暂存会话现场与连击进度，重新进入可准确接续。

### 6. 安装打包流水线
- **自包含安装包**：提供 Windows x64 自包含安装包（`Lexi-1.2.0-x64-setup.exe`），内置 .NET 8 运行时，用户端无需安装系统 .NET。
- **Native Helper 强校验**：构建流水线刚性依赖 `native\fsrs-optimizer\target\release\fsrs-optimizer.exe`，打包脚本包含前置与产物断言检查，确保优化器随包分发。
- **工作区输出收敛**：所有生成物默认输出至工作区内部目录（`Lexi 1.2.0 Windows\Lexi-1.2.0-Windows-x64`），避免污染外部桌面。

## 边界与验证声明

- **平台覆盖边界**：本次发布仅针对 Windows 10/11 x64 平台，不能宣称完整 macOS 的全部系统特性均已在 Windows 上实证，跨平台原生特性以各端独立验收为准。
- **验证范围说明**：不能宣称所有系统 DPI 缩放模式、极端跨日现场恢复及外部 AI 真实联网付费接口均已通过全面验证；AI 功能支持在设置中配置自定义兼容接口，默认支持本地离线使用。
- **验证细节归档**：关于自动化回归、单元契约测试、UI 冒烟与平台适配的当前具体验证数据与测试明细，另请参阅项目最终验收报告与测试日志，本文档不列举未经验收的统计数字。

# 1.1.4 · macOS 3.1.3 学习体验与长期记忆迁移

- 更新浅色默认界面、品牌图标、专注学习表面、独立学习计划与 IELTS 页面；创建计划支持搜索、分页、选词和每日词数。
- 今日重逢、专注学习和每日计划的真实评分接入 FSRS-6 长期排期；完成与撤销均写入可追溯轨迹。已有 FSRS 卡以新到期时间为准，旧词在首张新卡建立前沿用旧日期。
- 带入 21 参数个人训练、Context 校准和 Windows 本地优化器；样本不足时使用官方默认参数，本地积累达到门槛后才训练。
- 计划进度与长期排期通过待写队列协调；关闭或唤醒窗口保留当前页面。安装包仍保留个人数据目录。
- 重启后未完成的窗口学习轮次仍按当前界面规则重新开始，尚未达到 macOS 3.1.3 的完整轮次恢复能力。

# 1.1.3 · 跨端 CSV 与例句使用场景

- CSV 统一为与 Android 0.2.2 兼容的 29 列格式，并添加 CSV 导入入口；JSON 导入保留兼容。
- 例句偏好明确为“目标词在该场合怎么用”，避免把使用场景误当为话题。
- 已通过 13/13 自检与真实 Android CSV 文件往返读取。测试使用临时数据库，不修改用户库。
- 数据库结构不变。更新不替换用户词库；导入沿用重复跳过与事务保护。
- Android 端打印复习表移除英文释义；Windows 复习表原本只打印中文释义。

# 1.1.2 · 历史基线功能参考

- 统一侧栏“今日重逢”数字与实际待复习卡片队列，排除本轮已处理的词；全部处理后显示 0，重新置入今日或撤销复习后按实际待处理词数更新。
- 查词页新增 Alt+Space 入库快捷键，支持输入框焦点并处理 Windows 系统菜单冲突；连续按键不会重复保存已收藏词。
- 复习卡替换内容前完整退场，新卡片再平滑进入，避免旧动画结束回弹造成闪烁；切换页面会取消旧过渡，“减少动态效果”下直接切换。
- 新增独立「今日重逢」卡片：先看单词与音标，点击或按 Space 查看释义，再选择记得/还不熟；左右键可评级，保存成功后横向移出卡片。释义再长，评级按钮保持在底部。
- 词汇档案紧凑行增加来源/标签；设置分为外观、查词快捷方式、AI语境、数据备份、关于诊断。
- 代码拆分 Domain / Application / Infrastructure。
