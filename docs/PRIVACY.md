# 隐私与数据处理

Lexi 的核心学习功能本地优先。本说明描述当前公开源码与发行包的数据边界。

## 默认留在本机

- 离线词典查询不需要账号、网络或 AI Key。
- 词汇档案、原句、备注、标签、计划、学习轨迹、金句、统计和 FSRS 状态存储在本地。
- 个人 FSRS 参数训练和 Context 校准在本机运行，不上传学习记录。
- CSV、PDF 和本地备份由用户主动创建；密钥不写入词条 CSV。

## 可选 AI

AI 是用户配置的扩展能力。请求会发送当前词、用户选择的模块和必要语境到用户填写的服务地址。用户应确认服务商的数据留存、训练和计费政策，并只发送自己有权处理的内容。

Windows 使用平台受保护存储，macOS 使用钥匙串保存 API Key。公开源码不包含作者的接口地址、模型凭据或个人配置。

## 可选登录与一起学习

离线查词和学习不需要登录。登录仅在用户主动使用「一起学习」时发生：

- 通过 GitHub OAuth 建立账号会话。
- 同步账号资料、好友关系、当日学习达标和用户逐项授权的统计摘要。
- 头像与个人资料只对本人和已接受好友可见。
- 完整词库、逐词历史、计划内容、金句、音频和个人记忆模型不上传。

Cookie、OAuth access token、refresh token、Session、Supabase 管理密钥、数据库密码和服务端日志不进入源码、截图或 Release。

## 网络访问

- AI：只访问用户配置的服务。
- 登录和好友摘要：只在用户使用可选功能时访问配置的服务。
- 更新检查：读取 GitHub 公开 Release API，不携带用户 token、学习记录或本机标识。
- 第三方链接：只有用户主动打开时才访问外部网站。

## 发布与反馈

公开源码、截图和安装包不包含：

- 个人词库、计划、学习记录或记忆模型。
- 账号、好友资料、Cookie、Session、Token 或 API Key。
- 签名私钥、代理配置、连接日志或本机路径。
- 未获分发许可的额外第三方资料。

提交 Issue 或 PR 时不要附真实数据库、完整日志、Cookie、Token、密钥、签名材料或未脱敏截图。使用最小示例和隔离演示数据。

## 卸载与删除

Windows 安装更新和卸载不主动删除 `%LOCALAPPDATA%\Lexi`。macOS 卸载脚本默认保留 `~/Library/Application Support/Lexi/`。需要彻底删除时应先备份，再按平台文档明确选择删除数据；删除不可撤销。
