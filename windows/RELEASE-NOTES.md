# Lexi 1.2.1 · 学习交互与页面整理

相比 1.2.0，本版主要更新如下：

1. 修复同义词替换按钮无页面反馈，新增独立浏览、章节空状态、全部 555 组考点及搜索入口；浏览后再开始练习。
2. 三种学习入口统一快捷键，支持在设置中保存自定义映射、恢复默认和数字备用键开关。修复空格松开时触发返回按钮的问题，阻止长按重复评分；输入、菜单、抽屉按各自上下文处理。
3. 右上角增加全局专注入口。计划直接继续原学习会话，查词与档案使用主题匹配的学习卡，IELTS 保留教材身份；缺少来源时让用户选择。
4. 每日计划改为横向便签网格，在宽、中、窄窗口中呈现三、二、一列。管理动作收进菜单，调整计划使用侧边抽屉。
5. IELTS 支持跨章节多选管理、批量加入词汇档案，详情中也可收藏。已有档案词保留用户译文、笔记及原内容版本。
6. 听力与语法资料改分类卡片，长笔记独立阅读，保留本地 PDF/SVG/PNG 与录音；移除失效视频入口，本次未增加替代视频。
7. 词汇档案用分组“更多”菜单替代批量操作下拉框；操作名称采用“今日复习”，说明为“将所选词安排到今天”。
8. 主题与设置改为分类抽屉，打开设置不离开当前任务。英文模式修复句子翻译、金句本及已经打开的快速卡，语言切换保留草稿。
9. 全局快速卡片快捷键采用先申请、成功后切换的事务处理；任一新键被占用时保留原注册和持久化配置。

本版继续使用 FSRS-6 自适应复习算法。安装包包含运行环境、离线词库、教材资源与优化器，旧版目录保留。

由真实 Wolfpack 工人参与快捷键、教材和视觉组件工作，主控完成集成修复与实测。最终只读审查的结论经主控逐项复核；工人声明不作为测试通过证据。

验证包括真实 Avalonia 界面、Windows 全局热键注册冲突、宽窄/浅深色布局、学习记忆领域测试及隔离安装验收。详见 ACCEPTANCE.md。
